### Functional Oriented Programming (FOP)

Pure-functional programming has zero side-effects. Functional Oriented programming attempts to minimize side-effects, but uses them where it makes sense. In other words, in an imperative language, it's programming in a mostly-functional style.

### CaffeineScript Enhancements for Functional Oriented Programming
* [Everything Returns a Value](./Everything-Returns-a-Value.md)
* [Smart This-Binding](./Smart-This-Binding.md) helps bridge the FOP/OOP (Functional / Object Oriented Programming) gap
* [Comprehensions and Iteration](./Comprehensions-and-Iteration.md) allows you to express complex 'loops' in a declarative, functional way
* [Expressive Literals](./Expressive-Literals.md), including [Structuring](./Structuring.md), [Destructuring](./Destructuring.md) and [Restructuring](./Restructuring.md) allow you to construct and disassemble complex data-structures with little or no imperative code
* [Restructuring](./Restructuring.md) combines destructuring and structuring into a functionally-useful form
